# Takuma
My name is Takuma.

## Web app

ブラウザ版は `index.html` を開いて利用できます。ローカルサーバーを使う場合は、リポジトリのルートで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

ログイン情報:

- 先生: `sensei` / `1234`
- 生徒: `student` / `5678`

作成中はユーザー名とパスワードを空欄のまま送信すると、選択した役割で確認できます。パスワードを入力した通常ログインも引き続き利用できます。

先生は時間割セルをクリックして編集できます。編集内容はブラウザに自動保存され、`timetable.txt` としてダウンロードもできます。
